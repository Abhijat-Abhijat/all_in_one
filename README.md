# 🚀 All-in-One Productivity Dashboard

A Trello-style productivity dashboard built with HTML, TailwindCSS, and JavaScript.

---

## ✨ Features

### 📌 Task Management
- Drag & drop tasks (Todo → Done)
- Persistent storage (localStorage)
- Smooth animations

### 🔗 Link Manager
- Add/remove links
- Categorize using tags
- Search functionality

### 🍅 Pomodoro Timer
- 25-minute focus timer
- Tracks time spent
- Real-time analytics

### 📝 Notes
- Auto-saving notes section

### 📅 Daily Planner
- Quick planning input

### 📊 Analytics
- Tracks focus time

### ⌨️ Keyboard Shortcuts
- `Ctrl + K` → Search
- `Ctrl + N` → Add task

---

## 🎨 UI Highlights

- Trello-style board layout
- Smooth animations
- Hover effects
- Dark modern UI
- Responsive horizontal scrolling

---

## 🧱 Tech Stack

- HTML5
- TailwindCSS
- Vanilla JavaScript
- LocalStorage

---

git clone https://github.com/abhijat-abhijat/all-in-one-dashboard.git
